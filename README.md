# 🎬 YouTube Video Downloader

A Python script to download YouTube videos at your chosen resolution — from tiny 144p up to crisp 1080p. Built for reliability, small file sizes, and ease of use.

- ✅ Interactive quality selection (144p → 1080p)
- ✅ Automatic cookie repair (fixes common Netscape format issues)
- ✅ Works with age-restricted / bot-flagged videos (with valid cookies)
- ✅ Cross-platform — Windows, macOS, Linux
- ✅ Small output files thanks to efficient encoding
